SECOND TAKE for Windows
=======================

Recovery for corrupted camera clips (Sony XAVC S).
Originals are never modified: everything is written as a copy to the output folder.

PORTABLE VERSION (.zip)
  Unzip the whole folder and open "Second Take.exe".
  Don't delete the other files in the folder: the app needs them.

WINDOWS WARNING
  The first time, Windows may show "Windows protected your PC" (SmartScreen),
  because the app doesn't have a code-signing certificate yet.
  Click "More info" and then "Run anyway".

REPAIR VERIFICATION (optional)
  To have the app check repaired files frame by frame, install ffmpeg:
      winget install Gyan.FFmpeg
  Without it, repairs work normally, just without that check.
